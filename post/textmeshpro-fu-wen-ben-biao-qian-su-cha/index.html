TextMeshPro富文本标签速查

· 2026-05-22 · # 富文本 # UI # 字符串 # Unity # 知识库

TMP Rich Text 标签速查表+报错排查

一、标签速查（直接复制即用）

标签 作用 示例代码
<b></b> 粗体 普通<b>加粗</b>
<i></i> 斜体 普通<i>斜体</i>
<u></u> 下划线 普通<u>下划线</u>
<s></s> 删除线 <s>作废文字</s>
<allcaps></allcaps> 全大写 <allcaps>abc</allcaps>
<smallcaps></smallcaps> 小型大写 <smallcaps>text</smallcaps>
<color=值></color> 文字颜色 <color=red>红色</color>
<color=#00FFFF>青色</color>
<alpha=#数值> 透明度 正常<alpha=#50>半透明
<mark=色值></mark> 文字背景高亮 <mark=#FFEE00>高亮</mark>
<size=数值></size> 字号 <size=25>大号字</size>
<sup></sup> 上标 X<sup>2</sup>
<sub></sub> 下标 H<sub>2</sub>O
<align=方式> 对齐 left/center/right/justify
<indent=2em> 首行缩进 <indent=2em>缩进文本
<margin=10px></margin> 左右边距 <margin=15%>留白文字</margin>
<voffset=±数值></voffset> 垂直偏移 <voffset=8>上移</voffset>
<br> 强制换行 第一行<br>第二行
<sprite index=0> 插入图标 <sprite index=0 scale=1>
<link="id"></link> 点击链接 <link="click1">点击我</link>
<style="样式名"></style> 套用预设样式 <style>Title>标题</style>
<font="字体名"></font> 切换字体 <font="微软雅黑">换字体</font>

二、属性单位简写

  • px：像素
  • em：相对字号
  • %：百分比缩放
  • 颜色：英文名/#RGB/#RRGGBB/#RRGGBBAA

三、常用组合模板

// 促销价格
text = "<b><color=red><s>199</s></color></b> <color=green>99元</color>";
// 公式排版
text = "公式：A<sup>3</sup>+B<sub>1</sub>";
// 图标+文字
text = "积分 <sprite name=coin scale=0.8> 88";
// 高亮链接
text = "<mark=yellow><link=rule>查看规则</link></mark>";

四、通用书写规范

  1. TMP组件勾选Rich Text，标签才生效
  2. 标签成对闭合，嵌套顺序不能错乱
  3. 属性等号两侧无空格，写法color=red
  4. 后写标签样式覆盖前面样式

五、常见报错快速排查

  1. 标签原样显示不解析
    未勾选TMP面板 Rich Text，勾选即可。

  2. 颜色/大小样式无效
    标签未闭合、嵌套错乱、属性空格多余。

  3. Sprite图标空白不显示
    未创建TMP Sprite图集、索引/名称不匹配、图集未赋值。

  4. Link点击无响应
    未注册链接点击监听、linkID前后不一致。

  5. 文字错位偏移异常
    voffset、margin数值过大，缩进对齐混用冲突。

  6. 中文样式偶尔失效
    字体文件缺失富文本标记支持，更换标准TMP字体。
